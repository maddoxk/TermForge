# Installation

## From GitHub (current)

```bash
pip install git+https://github.com/maddoxk/TermForge
```

## From PyPI (upcoming)

```bash
pip install termforge
```

## Verify Installation

```bash
termforge-demo
```

## Requirements

- Python 3.10+
- Pillow >= 10.0 (image rendering)
- pyyaml >= 6.0 (declarative config)
- rich >= 13.0 (markup parsing)
